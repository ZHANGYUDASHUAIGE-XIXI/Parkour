# 校园少女角色资源

通过团结 AI 服务生成：混元生成模型与动作，MIA 生成人形骨架。原始模型、绑骨模型和各动作源文件均保留，方便后续调整。

场景角色使用 `Prefabs/CampusGirl_Player.prefab`，动画使用 `Animations/CampusGirl.controller`。旧角色和替换前场景均有备份，原游戏脚本保持不变。

正式动画为 `Animations/CampusGirl_Idle.anim`、`CampusGirl_Run.anim`、`CampusGirl_Jump.anim`、`CampusGirl_Slide.anim`、`CampusGirl_Death.anim`。同目录不带 `CampusGirl_` 前缀的是初始提取记录，控制器使用已重新烘焙根位移的正式版本。

正式 Avatar 为 `Model/CampusGirl_Humanoid.asset`。生成 FBX 的 Armature 自带 100 倍缩放，已在角色预制体中归一化骨架、重算蒙皮绑定并重建 Avatar；使用预制体中的 Avatar，避免换回原始 FBX 内的 Avatar。

## 动画参数

| Bool 参数 | 用途 | 默认值 |
| --- | --- | --- |
| IsJumping | 跳跃，与现有 PlayerController 参数一致 | false |
| IsSliding | 滑铲，与现有 PlayerController 参数一致 | false |
| IsPlaying | true 奔跑；false 待机 | true |
| IsDead | true 进入死亡状态 | false |

默认状态为 PlayerRun，以兼容现有脚本。Idle 和 Run 循环，Jump、Slide、Death 不循环。Jump 和 Slide 的状态播放速度分别对齐现有代码约 0.75 秒跳跃、0.8 秒滑铲。

## 需要自行接入的代码

菜单时将 `IsPlaying` 设为 false，开始游戏时设为 true。死亡时将 `IsDead` 设为 true，并保持 Animator 启用。当前 `PlayerController.Die()` 会设置 `animator.enabled = false`，因此死亡动画不会自动播放。本次依照约定没有修改这段代码。

Animator 的 Apply Root Motion 关闭，角色位移仍由现有 CharacterController 控制。跳跃动画的根节点纵向位移不叠加到现有跳跃轨迹；滑铲和死亡保留身体降低的姿态。
