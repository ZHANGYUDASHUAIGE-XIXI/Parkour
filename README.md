# 学姐快跑

> 3D 三车道无尽跑酷 · 个人独立开发作品集项目

《学姐快跑》是一款第三人称 3D 无尽跑酷游戏。玩家扮演学姐在校园大道上持续奔跑，通过左右变道、跳跃和滑铲躲避障碍、收集金币，不断刷新最高分。奔跑速度会随距离逐步提升，越往后越考验反应与操作节奏。

## 玩法特性

- **三车道跑酷**：在左、中、右三条车道间快速变道
- **跳跃与滑铲**：跳过矮障碍、滑过横杆、变道避开墙体
- **无尽赛道**：道路分段动态生成与回收，可无限奔跑
- **金币与计分**：分数 = 奔跑距离 + 金币 × 10，最高分本地存档
- **难度递增**：速度随奔跑距离提升，上限 16 m/s
- **完整游戏循环**：开始菜单 → 游戏 HUD → 死亡结算 → 重开

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 向左变道 | `A` / `←` |
| 向右变道 | `D` / `→` |
| 跳跃 | `Space` |
| 滑铲 | `S` / `↓` |
| 死亡后重开 | `R`（或点击结算界面按钮） |

## 技术亮点

- **泛型对象池 `ObjectPool<T>`**：统一管理道路片段、障碍与金币实例，替换运行时 `Instantiate/Destroy`，消除 GC 尖刺
- **分段式无尽生成**：按玩家位置流式生成前方赛道、回收身后路段，配合对象池稳定内存
- **运动学角色控制器**：基于 `CharacterController` 手写重力与变道插值，不依赖物理模拟，保证跑酷手感确定性
- **游戏状态机**：`Menu / Playing / GameOver` 三态流转，统一驱动 UI 与输入门控
- **事件解耦**：金币收集、状态切换通过 C# 事件广播，玩法逻辑与 UI 刷新互不依赖
- **动画状态机**：跑步 / 跳跃 / 滑铲状态切换，配合动画事件驱动逻辑复位
- **性能意识**：使用 Profiler 观察 GC 分配与帧率，验证对象池效果

## 技术栈

- **引擎**：团结引擎 1.10.4（Unity 2022.3 LTS 兼容，Built-in Render Pipeline）
- **语言**：C#
- **UI**：UGUI + TextMeshPro
- **动画**：Animator / Humanoid 角色动画
- **版本管理**：Git + GitHub

## 项目结构

```
Assets/
├─ Scripts/
│  ├─ Core/        # 对象池、游戏状态机、分数、UI、音频管理
│  ├─ Level/       # 赛道分段生成与回收
│  └─ Player/      # 角色控制、金币、障碍
├─ Prefabs/
│  ├─ Segments/    # 赛道片段
│  ├─ Obstacles/   # 矮障碍 / 横杆 / 墙体
│  └─ Collectible/ # 金币
├─ Scenes/         # SampleScene（主场景）
├─ CampusArt/      # 校园风格材质、网格、天空盒
├─ Character/      # 角色模型与动画
├─ Audio/          # BGM 与音效
└─ Materials/      # 通用材质
```

## 运行方式

1. 使用 **团结引擎 1.10.4**（或兼容的 Unity 2022.3 LTS）打开本项目
2. 打开场景 `Assets/Scenes/SampleScene.scene`
3. 点击 Play 即可试玩
4. 打包 Windows 版本：`File → Build Settings → Windows x64 → Build`
